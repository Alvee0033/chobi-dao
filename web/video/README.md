# Chobi Dao showcase video

The `ChobiDaoShowcase4K` Remotion composition renders the same eight animated scenes shown in `/showcase` as a clean 28-second 3840×2160 video at 30 fps. It includes the timed synthesized score and does not include the preview controls.

From `web/`, run `npm run video:render`. The MP4 is written to `video/out/chobi-dao-showcase-4k.mp4`. The soundtrack is regenerated from `video/scripts/render-audio.py` before each render.
