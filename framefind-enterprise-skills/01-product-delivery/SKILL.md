# FrameFind Product Delivery

## Mission
Convert PRD requirements into executable backlog items with traceable acceptance criteria.

## Scope anchors
- Feature specification (Section 6)
- User flows (Section 7)
- Roadmap and build order (Section 19)
- Open questions and ownership (Section 20)

## Workflow
1. Convert requested feature into epics and stories.
2. Add acceptance criteria tied to exact PRD behavior.
3. Add NFR criteria where relevant.
4. Identify blocked items from open questions.
5. Sequence by roadmap phase.
